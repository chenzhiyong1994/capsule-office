01 / A PLACE FOR EVERY AGENT

工作有条理，
灵感有空间。

把分散的会话放在眼前。
你来安排工作，办公室帮你看清进展。

⌘01

一人一席，各就各位

给 Agent 起名、分配项目目录、添加场景标签。在最多 5 个独立会话之间切换，随时找到正在做的事。

通过 xterm.js 与本地 PTY 操作 CLI。输入命令、发送 ESC、启停会话，继续使用你熟悉的交互方式。

02 / MAKE YOURSELF AT HOME

你的工作空间，
也可以很有个性。

点击左侧员工可切换 Claude Code / Codex CLI 会话，使用上方按钮暂停或重播。 所有操作与输出均为预设演示；真实 CLI 与项目操作需在本地桌面应用中使用。

03 / YOUR OFFICE IS ONE CLONE AWAY

下一个好点子，
从这里开工。

准备好 Windows、Git 和 Node.js 22.12+，
在本机安装并登录 Claude Code 或 Codex CLI。

阅读完整安装说明 ↗
第一次启动

点击「新增员工」，选择 Agent 和项目目录。权限模式建议先选「标准确认」；当前应用默认的「高风险自动确认」会跳过 CLI 审批，Codex 模式还会禁用沙箱。

TERMINAL / 本地安装 
git clone https://github.com/chenzhiyong1994/capsule-office.git
cd capsule-office
npm ci
npm run app
